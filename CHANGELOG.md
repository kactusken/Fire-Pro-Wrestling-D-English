# Changelog

## v1.0 (first release)
- Complete English translation: every menu and mode, help lines and messages, match settings,
  results, Title Match, league and tournament screens, Victory Road Kai, Options and Memory Card.
- The 220-wrestler roster (names, nicknames, profiles) in two patches, real names and the game's
  parody names, and all 1,000 move names.
- All of Edit Mode: Edit Wrestler (appearance, skills, parameters, moves, CPU logic), Edit
  Promotion, Edit Referee and the belt editor.
- Network mode: the DreamPassport 3 browser's 785 messages, its own strings, the upload form, and
  13 sheets of button, title and keyboard pictures redrawn in English.
- English pictures: the main menu buttons, the wrestler profile tags, the elimination order
  boards and the result banners.
- "(All Unlocked)" patches, English (both name sets) and Japanese: what L+R+Y at the main menu or
  winning every Victory Road title opens, from the start, plus the 100 downloadable moves and
  Spike's 50 downloadable wrestlers built in (no memory card needed), and a save guard that keeps
  them from overwriting a card file that wasn't loaded first.
